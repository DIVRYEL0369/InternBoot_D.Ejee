# 📊 Retail Sales Intelligence Dashboard

## 📌 Project Overview

This project is an end-to-end Machine Learning Sales Forecasting System built using Python, Scikit-learn, Pandas, and Streamlit.

The dashboard predicts retail sales and provides interactive business insights through visualizations and simulations.

---

# 🚀 Features

- 📈 Sales Forecast Prediction
- 🧮 Machine Learning Regression Model
- 🧪 Promotion Impact Simulation
- 🏬 Store Performance Analysis
- 📦 Product Family Insights
- 📊 Interactive Streamlit Dashboard
- ⚡ Real-time Prediction Controls

---

# 🧠 Machine Learning Workflow

## Data Preprocessing
- Date conversion
- Missing value checks
- Duplicate removal

## Feature Engineering
- Year, Month, Day extraction
- Weekday features
- Weekend flags
- Lag features
- Rolling mean features

## Model Building
- Multiple Linear Regression
- Train/Test Split
- Prediction & Evaluation
